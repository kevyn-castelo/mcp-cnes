# MCP CNES v0.1.1

A `v0.1.1` substitui a `v0.1.0` como versão recomendada. Ela mantém as 23
ferramentas MCP e os contratos funcionais da versão inicial, com endurecimento
de segurança, simplificação operacional e documentação revisada para a primeira
divulgação ampla do projeto.

## Destaques de segurança

- Importações e exports permanecem confinados aos diretórios autorizados, com
  rejeição de traversal, caminhos absolutos indevidos e links que escapem da raiz.
- `cnes_purge` exige habilitação administrativa e confirmação explícita antes de
  excluir lotes.
- Respostas MCP não publicam caminhos, endpoints, credenciais ou detalhes internos
  de exceções inesperadas.
- CodeQL, revisão de dependências, Dependabot, CODEOWNERS e auditoria das
  dependências travadas fazem parte do fluxo protegido do repositório.
- Bancos, caches, exports, cobertura, planilhas, arquivos de ambiente e datasets
  locais são excluídos do versionamento por padrão.

## Operação e manutenção

- `mcp-cnes` é o entrypoint público suportado para o servidor local via `stdio`.
- Wrappers, scrapers, diagnósticos e scripts de limpeza legados foram removidos.
- Testes e CI usam somente a arquitetura atual do pacote `mcp_cnes`.
- A documentação cobre instalação, diretórios de dados, fontes oficiais, retenção,
  cutover, rollback e operação segura.

## Instalação a partir da release

Requer [uv](https://docs.astral.sh/uv/) 0.12 ou superior e Python 3.11 ou superior.

```powershell
git clone --branch v0.1.1 --depth 1 https://github.com/kevyn-castelo/mcp-cnes.git
Set-Location mcp-cnes
uv sync --locked
uv run mcp-cnes
```

Consulte o [README do projeto](../../README.md) para configurar o servidor no
cliente MCP e executar a primeira consulta.

## Escopo e limitações

- O transporte suportado é local por `stdio`. Não exponha o processo diretamente
  na rede; um gateway remoto precisa acrescentar autenticação, autorização, TLS,
  limites de requisição e logs de auditoria.
- O CNES registra capacidade instalada. O projeto não calcula nem estima taxa de
  ocupação.
- Disponibilidade, atualização e estrutura dos arquivos dependem dos serviços
  oficiais do Portal SUS e do DATASUS.
- Telefone, e-mail, CNPJ e endereço são tratados como dados institucionais. CPF e
  nomes de pessoas físicas não fazem parte dos schemas ou exports do produto.
