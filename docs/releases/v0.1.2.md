# MCP CNES v0.1.2

A `v0.1.2` é a versão recomendada para a divulgação pública. Ela preserva o
endurecimento de segurança e as 23 ferramentas MCP da série `0.1`, corrigindo a
versão anunciada aos clientes durante o handshake.

## Correção desta versão

- A versão de runtime agora deriva da metadata instalada do pacote.
- `pyproject.toml`, metadata da distribuição, `mcp_cnes.__version__` e o servidor
  MCP anunciam o mesmo valor.
- Um teste regressivo impede novas divergências entre a versão empacotada e a
  versão observada pelos clientes.

A `v0.1.1` continha o mesmo código funcional e os mesmos controles de segurança,
mas sua metadata indicava `0.1.1` enquanto o handshake ainda informava `0.1.0`.
Sua tag e seus artefatos não foram reescritos; ela permanece disponível somente
como histórico rastreável.

## Segurança e operação

- Importações e exports ficam confinados aos diretórios autorizados.
- `cnes_purge` exige habilitação administrativa e confirmação explícita.
- Respostas MCP sanitizam caminhos, endpoints, credenciais e detalhes internos.
- CodeQL, revisão de dependências, Dependabot, CODEOWNERS e auditoria das
  dependências travadas protegem o fluxo do repositório.
- `mcp-cnes` permanece o entrypoint público suportado via `stdio`.

## Instalação a partir da release

Requer [uv](https://docs.astral.sh/uv/) 0.12 ou superior e Python 3.11 ou superior.

```powershell
git clone --branch v0.1.2 --depth 1 https://github.com/kevyn-castelo/mcp-cnes.git
Set-Location mcp-cnes
uv sync --locked
uv run mcp-cnes
```

Consulte o [README do projeto](../../README.md) para configurar o servidor no
cliente MCP e executar a primeira consulta.

## Escopo e limitações

- O transporte suportado é local por `stdio`; não exponha o processo diretamente
  na rede.
- O CNES registra capacidade instalada e não representa taxa de ocupação.
- Disponibilidade e formato dos arquivos dependem do Portal SUS e do DATASUS.
- CPF e nomes de pessoas físicas não fazem parte dos schemas ou exports do produto.

Reporte vulnerabilidades de forma privada conforme a
[política de segurança](../../SECURITY.md).
