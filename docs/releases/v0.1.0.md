# MCP CNES v0.1.0

A primeira versão pública do MCP CNES transforma dados oficiais do Cadastro
Nacional de Estabelecimentos de Saúde em ferramentas MCP para pesquisa e
qualificação de hospitais brasileiros.

## Destaques

- **23 ferramentas MCP:** ingestão, buscas, análises, validação e exports.
- **Duas fontes oficiais:** Hospitais e Leitos do Portal SUS e base completa mensal
  do DATASUS.
- **Contratos compatíveis:** as 19 ferramentas originais permanecem em `v1`; o
  contrato aditivo `v2` inclui razão social, CNPJ, mantenedora, endereço, contatos
  institucionais, geolocalização qualificada e leitos por tipo.
- **Inteligência comercial:** agrupamento por mantenedora, detecção de expansão,
  retração, entrada e saída, além de score transparente com pesos configuráveis.
- **Export pronto para CRM:** CSV, JSON, JSONL ou XLSX, com chave de deduplicação e
  proveniência da fonte, competência, lote, filtros, ETag e versão do contrato.
- **Integridade explícita:** dados ausentes permanecem ausentes; CPF e nomes de
  pessoas físicas não entram nos schemas ou arquivos gerados.

## Instalação a partir da release

Requer [uv](https://docs.astral.sh/uv/) 0.12 ou superior e Python 3.11 ou superior.

```powershell
git clone https://github.com/kevyn-castelo/mcp-cnes.git
Set-Location mcp-cnes
git checkout v0.1.0
uv sync --locked
uv run mcp-cnes
```

Consulte o [README do projeto](https://github.com/kevyn-castelo/mcp-cnes#readme)
para configurar o servidor em um cliente MCP, executar o Inspector e conhecer o
fluxo de carga das duas fontes.

## Escopo e limitações

Esta é uma release inicial, indicada para execução local e avaliação controlada.
Os arquivos de origem são mantidos por serviços públicos externos e podem ficar
temporariamente indisponíveis. O CNES registra capacidade instalada: o MCP não
calcula nem estima taxa de ocupação. Telefone, e-mail, CNPJ e endereço são tratados
como dados institucionais; CPF e nomes de pessoas físicas ficam fora do produto.

## Texto sugerido para anúncio

Hoje lançamos o **MCP CNES v0.1.0**, um servidor open source que conecta agentes de
IA aos dados oficiais do Cadastro Nacional de Estabelecimentos de Saúde.

Com ele, é possível pesquisar hospitais brasileiros por localização, porte e
perfil, identificar redes por CNPJ mantenedora, acompanhar sinais de expansão ou
retração, construir scores comerciais transparentes e exportar seleções auditáveis
prontas para CRM.

A primeira versão reúne 23 ferramentas MCP, integra o Portal SUS e a base completa
mensal do DATASUS e preserva compatibilidade entre os contratos `v1` e `v2`. Os
exports carregam a proveniência da consulta, e dados ausentes nunca são preenchidos
silenciosamente. O projeto também exclui CPF e nomes de pessoas físicas de seus
schemas e não inventa taxa de ocupação a partir de dados cadastrais.

O MCP CNES é distribuído sob licença MIT e já pode ser executado localmente com
Python e `uv`.
